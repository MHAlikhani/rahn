# RAHN Specification: Observation

Status: **Reserved.** Not normative; no implementation exists for this area yet.

Normative keywords: MUST / MUST NOT / SHOULD / SHOULD NOT / MAY (RFC 2119 sense). Normative language is used only where behavior is intentionally defined.

## Reserved

Observations, events, health, and provenance linking are Stage 4+ concerns. Reserved. When specified: observations MUST be linked to the state/transition they concern, and the observation pipeline MUST remain separable from decision-making.
