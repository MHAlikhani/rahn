# Stage 9 Report — v0.9.0-alpha: Programmability

Date: 2026-08-28. ADR: [0018](../../adr/0018-programmability-ir.md). Release: **v0.9.0-alpha**.

## Objective

Give external code a coherent, documented, stable programmatic model (charter Stage 9 gate): declare the public API surface, formalize the IR, and defer the DSL until evidence demands it.

## Architecture decision

- **The v0.9 IR already existed implicitly** and is now declared: the `Operation` vocabulary (the only way committed state changes) plus the canonical byte encoding (ADR 0003, format v2). Commits, sync payloads, CI reports, and future DSL output all compile down to or derive from these. A new IR language was rejected as speculative abstraction (ADR 0018).
- **`rahn-sdk` facade:** a zero-logic crate re-exporting the stable surface grouped by concern (model, IR, graph queries, observations, causality, verification, execution, persistence). Anything not reachable through `rahn-sdk` is internal and may change without notice.
- **Versioning policy:** pre-1.0, breaking SDK changes land in MINOR releases with CHANGELOG migration notes; patch releases never break; IR byte format changes only via format-version bump + ADR.
- **DSL: deferred** (reconsideration condition recorded in ADR 0018).

## Implementation changes

- `rahn-sdk` crate: `prelude` module + compile-time API-surface guards (tests that fail the build if the promised surface breaks). Doc examples run as doctests — examples are tests.
- Minor export fixes in `rahn-core`/`rahn-state`/`rahn-sim` (e.g. `Node`, `apply_all`, causal types, `SimulationBackend`) — additive only.
- No CLI changes.

## Tests

- 4 API-surface tests (model reachability, IR round-trip, verification + planning reachability, persistence round-trip).
- 3 doctests (build-and-verify, transitions, backend planning).
- Workspace: 137 tests green; fmt and clippy (`-D warnings`) clean.

## Limitations

- The facade is a curated view, not a new abstraction: it inherits all existing limitations (simulation-first, no addressing, per-replica sync transport cost).
- SDK stability is pre-1.0 (MINOR-breaking policy); no semver guarantees for internals.
- No language bindings beyond Rust (C++/Python bindings were charter-listed as optional future work).
- No DSL: authoring remains CLI/API-level.

## Next

**v1.0 — Stable Architecture**: the final stage; gated on stable semantics, documented APIs, trustworthy execution, credible security model, comprehensive tests, mature docs, and the final research review.
